# 🚀 SubFlux: Умный менеджер подписок с аналитикой расходов
## 📋 Краткое описание
SubFlux — это сервис для управления цифровыми подписками и анализа регулярных расходов.
Сервис помогает пользователю увидеть реальную финансовую картину, спрогнозировать будущие списания и осознанно управлять подписками.

⚠️ SubFlux __не обрабатывает платежи__ и не хранит платёжные данные. 
Он работает исключительно с учётом, аналитикой и прогнозированием.  
⚠️ Модель Payment используется __исключительно__ для учёта фактически произошедших списаний (сумма, валюта, дата), 
введённых вручную, импортированных или полученных из интеграций.

## ❓ Зачем нужен SubFlux
Современный пользователь часто имеет десятки подписок:
стриминг, сервисы, облака, инструменты, медиа.
Подписки:
- списываются автоматически
- меняют цены
- имеют разные периоды оплаты

В итоге человек не видит общей картины расходов.
__SubFlux__ решает эту проблему, помогая избавить пользователя от "цифрового хаоса" подписок и превращая подписки в структурированные данные и прогнозируемые расходы.

## 🎯 Цели проекта
- Структурировать цифровые подписки пользователя

- Отслеживать изменения цен

## 🎯 Ключевые возможности
### 📊 Учет и мониторинг
- Добавление подписок с различной периодичностью (ежемесячно, ежегодно, квартально)
- Категоризация подписок по типам (стриминг, облачные сервисы, ПО и т.д.)
- Автоматический расчет дат следующих платежей
- Отслеживание истории изменений цен
- Каталог доверенных тарифов (VerifiedPrice)
- Учёт истории цен пользовательских подписок
- Учёт фактических списаний (Payment)

### 🔔 Умные напоминания
- Персонализированные уведомления об оплате за 7, 3 и 1 день до платежа
- Настройка предпочтительных типов уведомлений (email, push)
- Напоминания об окончании триальных периодов
- Уведомления об изменениях тарифов

### 📈 Продвинутая аналитика
- Визуализация расходов по категориям
- Расчет месячных и годовых затрат
- Прогнозирование будущих расходов
- Тренды и изменения в расходах за период
- Сравнение фактических и планируемых расходов

### 🔄 Автоматизация
- Автоматическое обновление дат платежей после подтверждения оплаты
- Фоновая обработка напоминаний через Celery
- Еженедельные и ежемесячные отчеты
- Планируется импорт подписок из банковских выписок (CSV)

### ⚙️ Доп.функции
- ссылки на официальные страницы оплаты сервисов
- поддержка Web и Telegram-клиента

## 🏗️ Архитектура проекта

### Технологический стек:
- Backend: Django + Django REST Framework
- База данных: PostgreSQL
- Очереди задач: Redis + Celery
- Фронтенд: React.js / Vue.js (опционально)
- Деплой: Docker + Nginx
- Мониторинг: Flower для Celery
- Уведомления: Telegram Bot API + Email

️⚠️ Проект реализован/тестировался на __Django 6.0__ и требует __Python 3.12+__ 
(на более ранних версиях Django/Python __НЕ ТЕСТИРОВАЛСЯ__)

### Структура приложения (общая):
```
    subflux/
    ├── config/                # Конфигурация проекта
    ├── apps/
    │   ├── init.py
    │   ├── users/               # Пользователь и профиль
    │   ├── subscriptions/       # Основное приложение
    │   ├── analytics/           # Аналитика и отчеты
    │   └── notifications/       # Уведомления
    ├── utils/                   # Общие компоненты (логика работы с датами, конвертация валют и периодичностей, кастомные валидаторы)
    └── docs/                    # Документация
```
