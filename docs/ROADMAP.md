Данный документ отражает фактическое состояние проекта SubFlux, выполненные

Roadmap основан на реальном состоянии кода и не привязан к конкретным датам.

## Принципы развития проекта

- API-first (DRF)
- Доменная логика живёт в сервисном слое
- Асинхронные задачи через Celery
- Инварианты дублируются: сервисы + БД
- Цена никогда не переписывает прошлое
- VerifiedPrice — справочник, а не пользовательские данные
